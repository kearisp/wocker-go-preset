# GO preset for Wocker

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/kearisp/wocker-go-preset)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](./LICENSE)

A lightweight and efficient preset for developing golang applications with the Wocker workspace.


## Installation

You can add this preset to an existing Wocker project:

```shell
ws preset:install go
```
